# サンプル集

ichigocrate で動く BASIC プログラムのサンプル。どれも `core/tests/samples.rs` で、読み込めることと意図どおりに動くことをテストしている。

| ファイル | 内容 |
| --- | --- |
| [`net-oxo.bas`](net-oxo.bas) | 〇×ゲーム (三目並べ) のネット対戦。[ichigocrate-relay](https://github.com/Shiyo1101/ichigocrate-relay) を使う |

## 読み込み方

- **打ち込む**: ファイルの中身を 1 行ずつ打ち込む
- **デスクトップ版で GitHub から取り込む**: `NEW` の後に次を実行すると、各行がキー入力として流し込まれてプログラムとして登録される。URL は大文字小文字を区別するので、CapsLock を外して小文字で打つ

  ```basic
  GET "https://raw.githubusercontent.com/Shiyo1101/ichigocrate/main/samples/net-oxo.bas"
  ```

  Web 版からは取り込めない (GitHub が CORS の事前確認を許可していないため)。Web 版では埋め込み側の `loadProgram()` で読み込む

## net-oxo.bas (〇×ネット対戦)

2 台の ichigocrate で〇×ゲームを対戦する。手は中継サーバー [ichigocrate-relay](https://github.com/Shiyo1101/ichigocrate-relay) の受信箱を介してやりとりする。

### 中継サーバー

20 行目で、公開している中継サーバーを使う。

```basic
20 S="https://ichigocrate-relay.ichigocrate-relay.workers.dev"
```

Cloudflare の無料プランで動かしているので、利用が多いと 1 日の上限に達して使えなくなることがある。自分の中継サーバーを使う場合は、ichigocrate-relay を自分の Cloudflare アカウントにデプロイし (手順は ichigocrate-relay の README)、20 行目の URL を書き換える。

### 遊び方

1. 2 台とも `RUN` し、同じ部屋番号 (1〜9999) を入れる。プレイヤー番号は一方が `1` (O・先手)、もう一方が `2` (X・後手)
2. 自分の番 (`YOUR TURN`) になったら、置きたいマスの数字キー (1〜9) を押す。相手の番の間 (`WAIT...`) は、相手の手が届くのを待つ
3. 3 つ並べたほうの勝ち (`O WIN!` / `X WIN!`)。9 マス埋まれば引き分け (`DRAW`)

前の対戦の手が受信箱に残っていることがあるので、対戦ごとに違う部屋番号を使う。

### しくみ

| 箇所 | 内容 |
| --- | --- |
| 40〜50 行 | `S` の URL に `/r/<部屋番号 4 桁>/<A または B>` を付けて、NET 領域に 2 つの URL を組み立てる。`#1800` が自分の受信箱 (プレイヤー 1 は `A`、2 は `B`)、`#1880` が相手の受信箱 |
| 200〜240 行 | 相手の番: `NET GET` で自分の受信箱を問い合わせる。`NET()` が -1 (通信中) の間は待ち、0 (まだ届いていない) か -2 (失敗) なら 0.5 秒おいて問い合わせ直す。届いた手 (`1`〜`9` の 1 文字) は `#1200` に書き込まれる |
| 300〜330 行 | 自分の番: 押されたキーの手を `#1210` に置き、`POST` で相手の受信箱へ送る |
| 130〜150 行 | 勝ち判定。縦横斜めの 8 通りの並びを文字列 `D` から読む |

盤面は配列 `[0]`〜`[8]` (0: 空き、1: O、2: X) に持つ。プログラムは約 960 バイトで、`FREE()` の残りは約 60 バイト。
